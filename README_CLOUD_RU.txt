SMOKEHOUSE — ОБЩИЕ РЕЦЕПТЫ

Что добавлено:
- «Общие рецепты» загружаются из Supabase.
- Ты входишь через кнопку «Админ» и публикуешь/редактируешь рецепты.
- У остальных пользователей общие рецепты обновляются через интернет.
- Личные «Мои рецепты» остаются локальными и не перезаписываются.
- Общий рецепт можно нажать «Сохранить себе» и получить личную копию.
- При отсутствии интернета показывается последняя сохранённая копия общих рецептов.

НАСТРОЙКА SUPABASE:
1. Создай бесплатный проект на Supabase.
2. В SQL Editor выполни файл SUPABASE_SETUP.sql.
3. Authentication -> Users: создай свою учётку администратора.
4. Отключи публичную регистрацию новых пользователей.
5. Project Settings -> API:
   - скопируй Project URL
   - скопируй anon / publishable key
6. В файле cloud_config.js вставь эти два значения.
   Service Role key НЕ использовать.
7. Для GitHub Pages замени index.html, cloud_config.js, sw.js и остальные файлы из этого архива.

После этого:
- обычным пользователям вход не нужен;
- они видят «Общие рецепты»;
- ты нажимаешь «Админ», входишь и публикуешь рецепт;
- после обновления у других пользователей он появляется автоматически.
